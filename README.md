# 汉化联机hui整合
---
## 说明：
这是一个联机、汉化、字体、体验优化整合覆盖包\
由Huinight整合

适用于[Casualties: Unknown](https://store.steampowered.com/app/4576490/) Demo v7.0.1的

## 食用方式：
[点我下载](https://github.com/Hu1night/Casualties_Unknown-modpack/releases/latest/)然后解压覆盖到本体游戏.exe同目录即可

## 整合功能：
基于Steam的多人联机
<!-- 各种体验改善\ -->
解锁开发中的层级\
替换支持中文的字体\
基于wiki的物品描述
