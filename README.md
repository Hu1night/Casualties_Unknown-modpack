这是一个联机、汉化、字体、体验优化由 Huinight 整合的覆盖包

## 食用方式：
- [点我下载](https://github.com/Hu1night/Casualties_Unknown-modpack/releases/latest/)整合包
- 解压覆盖到游戏本体.exe同目录
- 在游戏内主菜单的设置-语言切换语言
- 按需调整Mod设置（整合包不提供预设）

在启用KrokMP联机Mod的情况下 你需要需要创建/加入房间才能游玩游戏

## 整合功能：
- 各种汉化
- 各种体验改善
- 基于Steam/IP连接的多人联机
- 解锁部分开发中的层级
- 替换像素字体
- 基于Wiki和解包的数值详细描述 (感谢维基简中维护&制作组)
