这是一个联机、汉化、字体、体验优化由 Huinight 整合的覆盖包

## 食用方式：
- [点我下载](https://github.com/Hu1night/Casualties_Unknown-modpack/releases/latest/)整合包
- 解压覆盖到游戏本体.exe同目录
- 在游戏内主菜单的设置-语言切换语言

默认需要创建/加入房间才能游玩（KrokMP多人联机mod）

## 整合功能：
- 基于Steam的多人联机
- 各种体验改善
- 解锁开发中的层级
- 替换支持中文的字体
- 基于wiki的物品描述
